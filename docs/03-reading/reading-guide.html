📕 阅读篇：自适应时代的阅读策略

新版阅读：约 27 分钟，35–48 题，三类题型，多阶段自适应。 特点是「题多、篇短、节奏快」——旧版一篇长文磨 18 分钟的打法彻底过时， 新版拼的是单位时间处理短文本的速度和准确率。

一、底层能力：长难句 + 主动阅读

不管题型怎么变，阅读的地基只有两块：

1. 长难句拆解（每天 5 句，坚持 4 周见效）

方法： 1. 找一句读不懂的句子，先自己划主干（谁 + 做了什么）； 2. 再把修饰成分（从句、非谓语、插入语、同位语）一层层挂回去； 3. 口头翻译一遍，对照参考译文； 4. 存进长难句本，三天后重读检验。

一个信号：当你发现自己「读英文句子不再需要回头重读」，这项训练就毕业了。

2. 主动阅读（预测 → 验证）

读每段之前先看首句，预测这段要讲什么，再读全段验证。这个习惯能把你从「逐词被动接收」升级为「带着框架抓信息」，直接提升做主旨题和结构题的速度。

二、三类新题型逐个击破

题型 1：Complete the Words（补全单词）

形式：一段学术文字，10 个单词各缺后半部分字母，如 The resea___ conducted expe___ ...

策略： 1. 先通读残段抓大意——上下文语境是第一线索； 2. 结合词性判断：缺词位置在句子里充当什么成分（动词？名词？）； 3. 利用构词法：常见词根词缀（-tion / -ment / -ally / re- / dis-）能直接锁定结尾； 4. 拼写必须准确——平时背单词要做「听音拼写」自测（见 词汇篇）。

日常训练：把任意英文段落丢给 AI 生成 C-test 练习（提示词在这里）。

题型 2：Read in Daily Life（日常阅读）

形式：邮件、公告、社交帖等 15–150 词短文本，每篇 2–3 题。

策略： 1. 先看题干再读文——短文本信息密度低，带着问题扫读效率翻倍； 2. 重点抓「五要素」：谁发的、给谁、要干什么、时间/地点、例外条件； 3. 小心「细则陷阱」：公告类文本的转折词（however / except / unless）后面几乎必出题。

日常训练：读英文邮件、Reddit 帖子、大学官网通知，这类材料到处都是。

题型 3：Read an Academic Passage（学术短文）

形式：约 200 词学术短文 + 5 题，最接近旧版阅读的浓缩版。

策略（按题型）： | 题型 | 做法 | | --- | --- | | 事实信息题 | 用题干关键词回文定位，答案一定有原文依据，别脑补 | | 词汇题 | 先看该词上下文再选，代入验证 | | 推断题 | 「正确的废话」不选，答案必须由原文必然推出 | | 否定事实题（EXCEPT） | 排除法：三个选项能定位到，剩下那个就是答案 | | 主旨/目的题 | 靠首句预测习惯 + 段落结构感，不要重读全文 |

三、自适应模式下的战术

  1. 第一阶段全力以赴：它决定你第二阶段的难度赛道和分数上限；
  2. 单题限时意识：题量 35–48 题、总时长约 27 分钟，平均每题 35–45 秒，一道题卡 90 秒还没头绪就选一个最可能的然后放手；
  3. 不可回溯：进入下一模块前系统会确认，养成「做完即放下」的心态；
  4. 变难 = 好消息：第二阶段感觉变难，说明你第一阶段打得好，稳住别慌。

四、精读训练法（每天 1 篇，最涨底力）

选一篇学术短文（旧版 TPO 文章切段用也可以）：

  1. 限时做题：按考试节奏完成；
  2. 无字典重读：标记所有不懂的词/句；
  3. 查证：查词 → 入 Anki；难句 → 拆解入长难句本；
  4. 段落大意：一句话概括每段（练结构感）；
  5. 错题归因：错在词汇 / 定位 / 理解 / 手滑？记入错题本。

一篇文章吃透 45 分钟，比刷三篇不复盘有用得多。

五、常见问题

Q：来不及做完怎么办？ A：新版题量大，做不完很常见。自适应计分下准确率优先于完成率，但空题没分——最后 1 分钟盲选也要填满。

Q：需要背学科背景知识吗？ A：不需要深度背景，但熟悉高频学科的基本概念和词汇（见 词汇篇·学科词）能显著降低理解负担。
